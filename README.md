# 从旅行灵感到消费决策

飞猪帮帮 Agent 策略思考，涵盖 OTA 业务判断、飞猪与豆包的旅行场景实测、C 端体验优化和北极星指标。

[在线文档](https://liziqun.github.io/fliggy-agent-strategy/)

## 核心观点

**飞猪帮帮的核心机会，是接住用户“已有出行意向、仍有关键取舍”的时刻，把旅行选择推进到可靠的预订与履约结果。**

- **竞争力判断：交易承接是基础，决策兑现才是壁垒。**飞猪拥有商品、评价、订单和服务体系，真正的优势取决于能否把这些资源组织起来：选前讲清取舍，订时核实条件，行程变化后协调处理。长期壁垒来自真实消费与服务结果对下一次决策的持续改善。
- **当前瓶颈：有操作入口，还缺少足够可靠的决策交付。**本轮评测中，帮帮更容易把需求接到商品和办理入口，但条件遗漏、文案与商品卡不一致、推荐依据不足，仍让用户承担核验成本。这直接影响用户是否愿意继续委托。
- **产品优先级：先做准，再做透，最后接续整趟旅行。**首先保证日期、预算等硬约束贯穿推荐到确认；其次用少量候选、地图和可追溯评价讲清“为什么适合、要付出什么代价”；再以同一趟旅行为单位保存条件、恢复任务，并基于订单状态推进值机、晚到入住和航变处理。
- **增长判断：围绕旅行任务的完成建立复用。**休闲旅行需求具有阶段性，应重点衡量每周完成的有效任务数、单趟旅行的服务深度，以及用户下次是否愿意再次委托。
